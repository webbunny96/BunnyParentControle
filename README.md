## 📖 Опис

**Parent Control** - це комплексна система батьківського контролю, яка дозволяє батькам керувати часом використання комп'ютера дитиною. Система працює на Windows та надає:

- Автоматичне блокування за розкладом (час сну)
- Встановлення ліміту часу роботи
- Миттєве блокування/розблокування через Telegram бота
- Локальний GUI інтерфейс з системним треєм
- Захист налаштувань батьківським паролем
- Просту реєстрацію адміністраторів через QR-код

## ✨ Основні можливості

### 🔒 Блокування комп'ютера

- **Розклад блокування**: Налаштування часу сну для кожного дня тижня
- **Ліміт часу**: Встановлення максимального часу роботи (15 хв, 30 хв, 1 год, 2 год або без ліміту)
- **Миттєве блокування**: Ручне блокування через Telegram бота
- **Вікно блокування**: Повноекранне вікно з відліком до вимкнення

### 📱 Telegram бот

- **Віддалене управління**: Блокування/розблокування з будь-якого місця
- **Перегляд статусу**: Інформація про поточний стан системи
- **Налаштування розкладу**: Зручне редагування часу сну для кожного дня
- **Управління системою**: Перезавантаження та вимкнення комп'ютера
- **Багатоадміністраторська підтримка**: Кілька батьків можуть керувати системою

### 🖥️ GUI додаток

- **System Tray**: Робота у фоновому режимі
- **Вікно налаштувань**: Налаштування токену бота та батьківського пароля
- **QR-код реєстрації**: Швидка реєстрація адміністраторів через QR-код
- **Захист паролем**: Доступ до налаштувань тільки з паролем
- **Валідація пароля**: Візуальні індикатори вимог безпеки до пароля в реальному часі

```

├── src/

│   │   ├── config.py      # Управління конфігурацією

│   │   └── scheduler.py   # Робота з розкладом

│   │   ├── main.py        # Точка входу бота
│   │   ├── handlers.py    # Обробники команд та callback

│   │   ├── tray_app.py     # System tray додаток
│   │   ├── settings_window.py  # Вікно налаштувань

│       ├── logger.py       # Логування
│       ├── qr_generator.py # Генерація QR-кодів

│       └── env_manager.py  # Управління .env файлом
```

### Компоненти системи

1. **Моніторинг (main.py)**: Головний сервіс, який постійно перевіряє конфігурацію та визначає, чи потрібно заблокувати комп'ютер
2. **Telegram бот (src/bot/)**: Асинхронний бот на aiogram 3.x для віддаленого управління
3. **GUI додаток (src/gui/)**: Tkinter додаток з system tray для локального управління
4. **Ядро (src/core/)**: Модулі конфігурації, моніторингу та розкладу

## 🚀 Встановлення

### Вимоги

- Python 3.8 або вище
- Windows 10/11
- Telegram бот (створений через [@BotFather](https://t.me/BotFather))

### Крок 1: Клонування репозиторію

```bash
git clone <repository-url>
cd parantControle
```

### Крок 2: Створення віртуального середовища

```bash
python -m venv venv
venv\Scripts\activate
```

### Крок 3: Встановлення залежностей

```bash
pip install -r requirements.txt
```

### Крок 4: Створення Telegram бота

1. Відкрийте Telegram та знайдіть [@BotFather](https://t.me/BotFather)
2. Надішліть команду `/newbot`
3. Дотримуйтесь інструкцій для створення бота
4. Збережіть отриманий токен

### Крок 5: Налаштування змінних середовища

Створіть файл `.env` в корені проекту:

```env
BOT_TOKEN="ваш_токен_бота"
```

## ⚙️ Налаштування

### Перший запуск

1. **Запустіть GUI додаток**:
   ```bash
   python src/gui/main.py
   ```

2. **Введіть токен Telegram бота** в вікні налаштувань

3. **Встановіть батьківський пароль** з дотриманням вимог безпеки:
   - Мінімум 8 символів
   - Великі літери (A-Z)
   - Малі літери (a-z)
   - Цифри (0-9)
   - Під час введення пароля ви побачите індикатори виконання вимог у реальному часі

4. **Підтвердіть пароль** (паролі повинні співпадати)

5. **Відскануйте QR-код** або введіть код реєстрації в Telegram боті

6. **Збережіть налаштування** (кнопка активується тільки коли всі вимоги виконані)

### Запуск сервісу моніторингу

Після налаштування запустіть головний сервіс:

```bash
python main.py
```

Сервіс автоматично запустить:
- **GUI додаток** (system tray) - для локального управління
- **Telegram бота** - як окремий процес
- **Моніторинг системи** - перевірка умов блокування

**Опції запуску:**

- **З GUI (за замовчуванням):**
  ```bash
  python main.py
  ```

- **Без GUI (тільки сервіс та бот):**
  ```bash
  python main.py --no-gui
  ```

**Поведінка:**
- При закритті GUI додатку автоматично завершується і головний скрипт `main.py`
- При зупинці через Ctrl+C коректно завершуються всі процеси (GUI, бот, моніторинг)
- Показує QR-код та код реєстрації в консолі (якщо адміністратор не зареєстрований)

### Telegram бот

Після реєстрації через QR-код або код, ви отримаєте доступ до меню з наступними опціями:

#### Головне меню

- **🔒 Заблокувати** - Миттєве блокування комп'ютера
- **🔓 Розблокувати** - Розблокування комп'ютера
- **📅 Розклад** - Налаштування розкладу блокування
- **📊 Статус** - Перегляд поточного стану системи
- **🔑 Змінити батьківський пароль** - Зміна пароля доступу
- **🔄 Перезавантажити** - Перезавантаження комп'ютера
- **🛑 Вимкнути ПК** - Вимкнення комп'ютера

#### Налаштування розкладу

1. Натисніть **📅 Розклад** в головному меню
2. Виберіть день тижня (Пн-Нд)
3. Налаштуйте:
   - **Увімкнути/Вимкнути** розклад для цього дня
   - **Час початку** блокування (формат HH:MM)
   - **Час кінця** блокування (формат HH:MM)

#### Встановлення ліміту часу

1. Натисніть **📊 Статус**
2. Виберіть потрібний ліміт часу (15 хв, 30 хв, 1 год, 2 год або без ліміту)
3. Ліміт почне відлік від моменту встановлення

### GUI додаток

GUI додаток працює у системному треї та надає:

- **Відкрити налаштування** - Відкриває вікно налаштувань (потрібен пароль)
- **Вихід** - Закриває додаток (потрібен пароль)

### Логіка блокування

Система блокує комп'ютер якщо виконується **хоча б одна** з умов:

1. **Force block** - Ручне блокування через бота (найвищий пріоритет)
2. **Ліміт часу** - Перевищення встановленого ліміту часу роботи
3. **Розклад** - Поточний час в межах активного розкладу блокування

### Вікно блокування

Коли система визначає потребу в блокуванні:

1. З'являється повноекранне вікно з відліком до вимкнення (60 секунд)
2. Вікно блокує ввід (миша та клавіатура)
3. Відображається QR-код та код реєстрації (якщо адміністратор не зареєстрований)
4. Після відліку комп'ютер вимикається

**Розблокування**: Вікно автоматично закривається, якщо адміністратор розблокує комп'ютер через Telegram бота.

## 📁 Структура проекту

### Файли конфігурації

- **config.json**: Основна конфігурація системи
  ```json
  {
    "admin_ids": [123456789],
    "otp": "ABCD1234",
    "parent_password": "example_password",
    "force_block": false,
    "time_limit_minutes": 0,
    "start_time": 0,
    "schedule": {
      "0": {
        "start": "22:00",
        "end": "07:00",
        "enabled": true
      }
    }
  }
  ```
  
  **Примітка:** JSON не підтримує коментарі. Дивіться `config.example.md` для детального опису полів.

- **.env**: Змінні середовища
  ```env
  BOT_TOKEN="ваш_токен_бота"
  ```

### Основні модулі

#### src/core/config.py
Управління конфігурацією системи:
- `load_config()` - Завантаження конфігурації
- `save_config()` - Збереження конфігурації
- `normalize_config()` - Нормалізація конфігурації
- `validate_config()` - Валідація конфігурації

#### src/core/monitor.py
Моніторинг та логіка блокування:
- `should_block()` - Визначення потреби в блокуванні
- `monitor_logic()` - Головний цикл моніторингу
- `get_time_remaining()` - Отримання залишку часу
- `get_status_info()` - Інформація про стан системи

#### src/core/scheduler.py
Робота з розкладом:
- `is_within_schedule()` - Перевірка чи поточний час в розкладі
- `get_current_day_schedule()` - Отримання розкладу на сьогодні
- `validate_time_format()` - Валідація формату часу
- `validate_schedule()` - Валідація розкладу

#### src/bot/handlers.py
Обробники команд та callback для Telegram бота:
- `cmd_start_handler()` - Обробка команди /start
- `process_callbacks_handler()` - Обробка callback запитів
- `handle_block_callback()` - Обробка блокування
- `handle_schedule_callback()` - Обробка розкладу

#### src/gui/tray_app.py
System tray додаток:
- `TrayApp` - Головний клас додатку
- `show_settings()` - Показ вікна налаштувань
- `_setup_tray()` - Налаштування system tray

#### src/gui/blocking_window.py
Вікно блокування:
- `BlockingWindow` - Клас вікна блокування
- `_set_block_input()` - Блокування вводу
- `_shutdown_system()` - Вимкнення системи

## 📦 Збірка в exe файл

Проект можна зібрати в один виконуваний exe файл для Windows за допомогою PyInstaller.

### Швидкий старт

1. **Встановіть PyInstaller** (якщо ще не встановлено):
   ```bash
   pip install pyinstaller
   ```

2. **Запустіть скрипт збірки**:
   ```powershell
   # PowerShell
   .\build.ps1
   
   # Або Python
   python build.py
   ```

3. **Результат**: Один exe файл буде в директорії `dist/`:
   - `parent_control.exe` - Всі компоненти (сервіс, бот, GUI) в одному файлі

### Розповсюдження

Для розповсюдження скопіюйте exe файл разом з:
- `config.json` (створюється автоматично при першому запуску)
- `.env` файл з `BOT_TOKEN`

Детальні інструкції дивіться в [docs/BUILD.md](docs/BUILD.md).

1. **Додавання нової команди в бот**:
   - Додайте обробник в `src/bot/handlers.py`

   - Додайте кнопку в `src/bot/keyboards.py` (якщо потрібно)

2. **Додавання нового поля в конфігурацію**:
   - Оновіть `normalize_config()` в `src/core/config.py`

   - Оновіть документацію

3. **Додавання нового типу блокування**:
   - Оновіть `should_block()` в `src/core/monitor.py`
   - Додайте логіку в `monitor_logic()`

## 🔐 Безпека

### Захист паролем

- Батьківський пароль зберігається в `config.json` у відкритому вигляді
- Рекомендується використовувати сильний пароль (мінімум 8 символів)
- Пароль потрібен для:
  - Доступу до налаштувань через GUI
  - Закриття програми
  - Зміни пароля через бота

### Telegram бот

- Токен бота зберігається в `.env` файлі (не комітити в git!)
- Реєстрація адміністраторів через QR-код або код
- Підтримка кількох адміністраторів

### Блокування вводу

- Використовується Windows API `BlockInput()` для блокування миші та клавіатури
- Потрібні права адміністратора для роботи
- Блокування автоматично знімається при вимкненні системи

## 🐛 Відомі проблеми та обмеження

1. **Windows only**: Система працює тільки на Windows через використання Windows API
2. **Права адміністратора**: Для повної функціональності потрібні права адміністратора
3. **Блокування вводу**: Може не працювати на деяких системах без прав адміністратора
4. **Пароль в конфігурації**: Пароль зберігається у відкритому вигляді (не зашифрований)
