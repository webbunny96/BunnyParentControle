# Інструкція зі збірки exe файлу

Цей документ описує процес збірки проекту Parent Control в один виконуваний exe файл для Windows.

## Вимоги

- Python 3.8 або вище
- Windows 10/11
- Всі залежності з `requirements.txt` встановлені

## Встановлення PyInstaller

Якщо ви ще не встановили PyInstaller:

```bash
pip install pyinstaller
```

Або встановіть всі залежності:

```bash
pip install -r requirements.txt
```

## Збірка проекту

### Автоматична збірка (рекомендовано)

Використовуйте один з готових скриптів:

**PowerShell:**
```powershell
.\build.ps1
```

**Python:**
```bash
python build.py
```

Скрипт автоматично збере весь проект в один exe файл:
- `parent_control.exe` - Всі компоненти (сервіс, бот, GUI) в одному файлі

### Ручна збірка

Якщо потрібно зібрати вручну:

```bash
pyinstaller --clean parent_control.spec
```

## Результат збірки

Після успішної збірки exe файл буде знаходитись в директорії `dist/`:

```
dist/
└── parent_control.exe
```

## Розповсюдження

Для розповсюдження програми скопіюйте:

1. **parent_control.exe** з директорії `dist/`
2. **config.json** (або створіть новий при першому запуску)
3. **.env файл** з BOT_TOKEN (або створіть новий)

Структура папки для розповсюдження:

```
ParentControl/
├── parent_control.exe
├── config.json
└── .env
```

## Запуск зібраної програми

### Перший запуск

1. Створіть файл `.env` з токеном бота:
   ```
   BOT_TOKEN="ваш_токен_бота"
   ```

2. Запустіть `parent_control.exe`:
   ```bash
   parent_control.exe
   ```

3. При першому запуску створиться `config.json` з дефолтними налаштуваннями

4. Відскануйте QR-код або введіть код реєстрації в Telegram боті

### Звичайний запуск

Просто запустіть `parent_control.exe`:

```bash
parent_control.exe
```

Або з опціями:

```bash
# Без GUI (тільки сервіс та бот)
parent_control.exe --no-gui
```

## Налаштування spec файлу

Якщо потрібно змінити параметри збірки, відредагуйте файл `parent_control.spec`:

### Основні параметри

- `console=True/False` - показувати консоль (True за замовчуванням)
- `name` - ім'я вихідного exe файлу (за замовчуванням `parent_control`)
- `hiddenimports` - додаткові модулі для включення
- `datas` - додаткові файли для включення

## Вирішення проблем

### Помилка "ModuleNotFoundError"

Якщо після збірки виникає помилка про відсутність модуля:

1. Додайте модуль до `hiddenimports` в `parent_control.spec`
2. Перезберіть проект:
   ```bash
   pyinstaller --clean parent_control.spec
   ```

### Великий розмір exe файлу

Exe файл може бути досить великим (80-150 МБ) через включення всіх залежностей та компонентів. Це нормально для однопроцесного exe файлу.

Для зменшення розміру можна:

1. Виключити непотрібні модулі через `excludes` в `parent_control.spec`
2. Використати UPX для стиснення (вже включено в spec файл)
3. Видалити непотрібні залежності з `hiddenimports`

### Антивірус блокує exe файли

Деякі антивіруси можуть блокувати зібрані exe файли через підозрілу поведінку. Це помилкове спрацювання.

Рішення:

1. Додайте exe файли до винятків антивірусу
2. Підпишіть exe файли цифровим сертифікатом (для продакшн використання)

### Помилка при запуску exe

Якщо exe файл не запускається:

1. Перевірте чи всі необхідні файли (config.json, .env) присутні
2. Запустіть exe з консолі щоб побачити помилки:
   ```bash
   parent_control.exe
   ```
3. Перевірте логи в консолі
4. Переконайтеся що всі залежності включені в `hiddenimports` в spec файлі
