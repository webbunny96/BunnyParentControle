## Проблеми з встановленням

### Проблема: "pip install" не працює

**Симптоми:**
- Помилка при встановленні залежностей
- "pip is not recognized"

**Рішення:**

1. Перевірте чи встановлений Python:
   ```bash
   python --version
   ```

2. Перевірте чи встановлений pip:
   ```bash
   python -m pip --version
   ```

3. Оновіть pip:
   ```bash
   python -m pip install --upgrade pip
   ```

4. Встановіть залежності:
   ```bash
   python -m pip install -r requirements.txt
   ```

### Проблема: Помилки при встановленні залежностей

**Симптоми:**
- Помилки компіляції
- Відсутні бібліотеки

**Рішення:**

1. Встановіть Visual C++ Build Tools (для Windows)
2. Перевірте версію Python (потрібна 3.8+)
3. Спробуйте встановити залежності по одній:
   ```bash
   pip install paramiko
   pip install schedule
   pip install aiogram
   # і т.д.
   ```

## Проблеми з Telegram ботом

### Проблема: Бот не відповідає

**Симптоми:**
- Команди не обробляються
- Бот не реагує на повідомлення

**Рішення:**

1. **Перевірте токен бота:**
   - Відкрийте файл `.env`
   - Переконайтеся що токен правильний
   - Перевірте чи немає зайвих пробілів

2. **Перевірте чи запущений сервіс:**
   ```bash
   python main.py
   ```

3. **Перевірте логи:**
   - Шукайте помилки в консолі
   - Перевірте чи бот запустився

4. **Перезапустіть бота:**
   - Зупиніть сервіс (Ctrl+C)
   - Запустіть знову

### Проблема: "BOT_TOKEN not found"

**Симптоми:**
- Помилка "BOT_TOKEN not found in .env file!"
- Бот не запускається

**Рішення:**

1. **Перевірте наявність файлу `.env`:**
   ```bash
   dir .env
   ```

2. **Перевірте формат файлу:**
   ```env
   BOT_TOKEN="ваш_токен"
   ```
   Або:
   ```env
   BOT_TOKEN=ваш_токен
   ```

3. **Перевірте чи токен правильний:**
   - Токен має бути отриманий від @BotFather
   - Формат: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

### Проблема: Не можу зареєструватися як адміністратор

**Симптоми:**
- QR-код не працює
- Код реєстрації не приймається

**Рішення:**

1. **Перевірте код реєстрації:**
   - Відкрийте `config.json`
   - Знайдіть поле `"otp"`
   - Переконайтеся що код правильний

2. **Спробуйте через код:**
   - Скопіюйте код з `config.json`
   - Надішліть боту в Telegram
   - Натисніть `/start` з кодом

3. **Перевірте чи бот запущений:**
   - Запустіть `python main.py`
   - Перевірте чи є помилки

### Проблема: Бот не бачить зміни конфігурації

**Симптоми:**
- Зміни в конфігурації не застосовуються
- Бот показує старий статус

**Рішення:**

1. **Перезапустіть бота:**
   - Зупиніть сервіс
   - Запустіть знову

2. **Перевірте чи конфігурація збережена:**
   - Відкрийте `config.json`
   - Переконайтеся що зміни збережені

3. **Перевірте права доступу:**
   - Переконайтеся що файл `config.json` не заблокований
   - Перевірте права на запис

## Проблеми з GUI

### Проблема: GUI не запускається

**Симптоми:**
- Помилка при запуску
- Вікно не з'являється
- GUI не запускається при `python main.py`

**Рішення:**

1. **Перевірте залежності:**
   ```bash
   pip install pystray pillow tkinter
   ```

2. **Перевірте Python версію:**
   ```bash
   python --version
   ```
   Потрібна версія 3.8+

3. **Запустіть з правами адміністратора:**
   - Клацніть правою кнопкою на файл
   - Виберіть "Запустити від імені адміністратора"

4. **Спробуйте запустити GUI окремо:**
   ```bash
   python src/gui/main.py
   ```
   Якщо це працює, проблема може бути в `main.py`

5. **Запустіть без GUI для діагностики:**
   ```bash
   python main.py --no-gui
   ```
   Це допоможе визначити чи проблема в GUI чи в інших компонентах

### Проблема: System tray не відображається

**Симптоми:**
- Іконка не з'являється в треї
- Немає доступу до меню

**Рішення:**

1. **Перевірте чи встановлений pystray:**
   ```bash
   pip install pystray
   ```

2. **Перевірте чи є іконка в треї:**
   - Перевірте область сповіщень Windows
   - Можливо іконка прихована

3. **Перезапустіть GUI:**
   - Закрийте додаток
   - Запустіть знову

### Проблема: QR-код не генерується

**Симптоми:**
- QR-код не відображається
- Помилка генерації

**Рішення:**

1. **Перевірте токен бота:**
   - Введіть правильний токен
   - Переконайтеся що токен валідний

2. **Перевірте залежності:**
   ```bash
   pip install qrcode pillow
   ```

3. **Перевірте підключення до інтернету:**
   - QR-код потребує підключення до Telegram API
   - Перевірте чи є інтернет

## Проблеми з блокуванням

### Проблема: Комп'ютер не блокується

**Симптоми:**
- Вікно блокування не з'являється
- Комп'ютер не вимикається

**Рішення:**

1. **Перевірте чи запущений сервіс:**
   ```bash
   python main.py
   ```

2. **Перевірте конфігурацію:**
   - Відкрийте `config.json`
   - Перевірте `force_block`, `time_limit_minutes`, `schedule`

3. **Перевірте права адміністратора:**
   - Блокування вводу потребує прав адміністратора
   - Запустіть сервіс з правами адміністратора

4. **Перевірте логи:**
   - Шукайте помилки в консолі
   - Перевірте чи є повідомлення про блокування

### Проблема: Блокування вводу не працює

**Симптоми:**
- Миша та клавіатура все ще працюють
- Можна закрити вікно блокування

**Рішення:**

1. **Запустіть з правами адміністратора:**
   - Клацніть правою кнопкою на файл
   - Виберіть "Запустити від імені адміністратора"

2. **Перевірте Windows версію:**
   - `BlockInput()` може не працювати на деяких версіях Windows
   - Перевірте версію Windows

3. **Перевірте антивірус:**
   - Деякі антивіруси блокують `BlockInput()`
   - Додайте виняток для програми

### Проблема: Вікно блокування не закривається

**Симптоми:**
- Вікно блокування не закривається після розблокування
- Комп'ютер вимикається навіть після розблокування

**Рішення:**

1. **Перевірте чи сервіс моніторингу працює:**
   - Сервіс має моніторити конфігурацію та закривати вікно
   - Перевірте чи сервіс запущений

2. **Перезапустіть сервіс:**
   - Зупиніть сервіс (Ctrl+C)
   - Запустіть знову

3. **Перевірте конфігурацію:**
   - Відкрийте `config.json`
   - Переконайтеся що `force_block` = `false`

## Проблеми з паролем

### Проблема: Пароль не приймається при встановленні

**Симптоми:**
- Кнопка "Зберегти" не активується
- Повідомлення про невалідний пароль
- Індикатори вимог показують помилки

**Рішення:**

1. **Перевірте вимоги до пароля:**
   - Мінімум 8 символів
   - Великі літери (A-Z)
   - Малі літери (a-z)
   - Цифри (0-9)

2. **Перевірте індикатори в GUI:**
   - Всі індикатори повинні бути зеленими (✅)
   - Якщо є червоні (❌), виправте відповідні вимоги

3. **Перевірте співпадіння паролів:**
   - Пароль та підтвердження повинні співпадати
   - Переконайтеся що немає зайвих пробілів

**Приклад валідного пароля:**
- `MyPass123` ✅
- `Parent2024` ✅
- `SecurePass1` ✅

**Приклади невалідних паролів:**
- `pass` ❌ (занадто короткий)
- `PASSWORD` ❌ (немає малих літер та цифр)
- `password123` ❌ (немає великих літер)

### Проблема: Пароль не приймається в Telegram боті

**Симптоми:**
- Повідомлення про помилки валідації
- Пароль не зберігається

**Рішення:**

1. **Перевірте вимоги до пароля** (див. вище)

2. **Прочитайте повідомлення про помилки:**
   - Бот показує детальний список невиконаних вимог
   - Виправте всі помилки перед повторною спробою

3. **Переконайтеся що пароль відповідає всім вимогам:**
   - Перевірте кожну вимогу окремо
   - Використовуйте комбінацію великих/малих літер та цифр

### Проблема: Забув пароль

**Симптоми:**
- Неможливо відкрити налаштування
- Пароль не приймається

**Рішення:**

1. **Спробуйте відновити через Telegram бота:**
   - Відкрийте бота
   - Натисніть "🔑 Змінити батьківський пароль"
   - Введіть новий пароль з дотриманням вимог

2. **Якщо немає доступу до бота:**
   - Видаліть файл `parent_control.db` (або `config.json` якщо використовується старий формат)
   - Перезапустіть програму
   - Встановіть новий пароль при першому запуску

**Увага:** Видалення бази даних призведе до втрати всіх налаштувань!

## Проблеми з конфігурацією

### Проблема: Конфігурація не зберігається

**Симптоми:**
- Зміни не зберігаються
- Файл `config.json` не оновлюється

**Рішення:**

1. **Перевірте права доступу:**
   - Переконайтеся що є права на запис
   - Перевірте чи файл не заблокований

2. **Перевірте чи файл існує:**
   ```bash
   dir config.json
   ```

3. **Перевірте формат JSON:**
   - Відкрийте `config.json`
   - Перевірте чи JSON валідний
   - Використайте JSON валідатор

### Проблема: Конфігурація пошкоджена

**Симптоми:**
- Помилки при завантаженні конфігурації
- Система не працює

**Рішення:**

1. **Створіть резервну копію:**
   ```bash
   copy config.json config.json.backup
   ```

2. **Відновіть конфігурацію:**
   - Видаліть `config.json`
   - Запустіть систему (створиться нова конфігурація)
   - Налаштуйте знову

3. **Перевірте JSON формат:**
   - Використайте JSON валідатор
   - Перевірте чи всі поля присутні

## Інші проблеми

### Проблема: Помилки при запуску

**Симптоми:**
- Різні помилки при запуску
- Система не працює

**Рішення:**

1. **Перевірте версію Python:**
   ```bash
   python --version
   ```
   Потрібна версія 3.8+

2. **Перевірте залежності:**
   ```bash
   pip list
   ```
   Переконайтеся що всі залежності встановлені

3. **Перевірте логи:**
   - Шукайте помилки в консолі
   - Перевірте stack trace

### Проблема: Високе споживання ресурсів

**Симптоми:**
- Високе використання CPU
- Високе використання пам'яті

**Рішення:**

1. **Перевірте інтервал моніторингу:**
   - За замовчуванням: 10 секунд
   - Можна збільшити в `main.py`

2. **Перевірте чи немає зациклених процесів:**
   - Перевірте Task Manager
   - Закрийте зайві процеси

3. **Перезапустіть систему:**
   - Зупиніть всі процеси
   - Запустіть знову

### Проблема: Логи не зберігаються

**Симптоми:**
- Логи не записуються в файл
- Немає файлу логів

**Рішення:**

1. **Перевірте налаштування логування:**
   - Відкрийте `src/utils/logger.py`
   - Перевірте чи вказано шлях до файлу

2. **Створіть директорію для логів:**
   ```bash
   mkdir logs
   ```

3. **Перевірте права доступу:**
   - Переконайтеся що є права на запис
   - Перевірте чи директорія існує
