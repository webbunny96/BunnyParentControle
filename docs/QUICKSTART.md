# Швидкий старт

Покрокова інструкція для швидкого запуску системи батьківського контролю.

## Передумови

- Windows 10/11
- Python 3.8+
- Telegram акаунт
- Telegram бот (створений через @BotFather)

## Крок 1: Встановлення

### 1.1 Клонування репозиторію

```bash
git clone <repository-url>
cd parantControle
```

### 1.2 Створення віртуального середовища

```bash
python -m venv venv
venv\Scripts\activate
```

### 1.3 Встановлення залежностей

```bash
pip install -r requirements.txt
```

## Крок 2: Створення Telegram бота

### 2.1 Створення бота через BotFather

1. Відкрийте Telegram
2. Знайдіть [@BotFather](https://t.me/BotFather)
3. Надішліть команду `/newbot`
4. Введіть ім'я бота (наприклад, "Parent Control Bot")
5. Введіть username бота (наприклад, "parent_control_bot")
6. Збережіть отриманий токен

### 2.2 Створення .env файлу

Створіть файл `.env` в корені проекту:

```env
BOT_TOKEN="ваш_токен_від_BotFather"
```

**Приклад:**
```env
BOT_TOKEN="1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"
```

## Крок 3: Перший запуск

### 3.1 Запуск GUI додатку

```bash
python src/gui/main.py
```

### 3.2 Налаштування

1. **Введіть токен бота** в поле "Токен Telegram боту"
2. **Встановіть батьківський пароль** (мінімум 4 символи)
3. **Підтвердіть пароль**
4. **Відскануйте QR-код** або скопіюйте код реєстрації
5. **Натисніть "Зберегти"**

### 3.3 Реєстрація в Telegram боті

**Варіант 1: Через QR-код**
1. Відкрийте Telegram на телефоні
2. Відскануйте QR-код з вікна налаштувань
3. Натисніть "Start" в боті

**Варіант 2: Через код**
1. Скопіюйте код реєстрації з вікна налаштувань
2. Відкрийте Telegram бота
3. Надішліть код боту
4. Натисніть "Start"

Після реєстрації ви побачите головне меню з кнопками управління.

## Крок 4: Запуск системи

### 4.1 Запуск головного сервісу

**Рекомендований спосіб (запускає все разом):**
```bash
python main.py
```

Це автоматично запустить:
- ✅ GUI додаток (system tray)
- ✅ Telegram бота
- ✅ Сервіс моніторингу

**Альтернативні способи:**

- **Без GUI (тільки сервіс та бот):**
  ```bash
  python main.py --no-gui
  ```

- **Тільки GUI:**
  ```bash
  python src/gui/main.py
  ```

- **Тільки бот:**
  ```bash
  python src/bot/main.py
  ```

### 4.2 Перевірка роботи

Сервіс виведе в консоль:
- QR-код для реєстрації (якщо адміністратор не зареєстрований)
- Код реєстрації
- Повідомлення про запуск GUI додатку
- Повідомлення про запуск бота
- Логи моніторингу

**Важливо:** 
- GUI додаток з'явиться у system tray (область сповіщень Windows)
- При закритті GUI додатку автоматично завершиться і головний скрипт `main.py`
- Для коректного завершення всіх процесів використовуйте Ctrl+C або закрийте GUI

### 4.3 Тестування

1. **Тест блокування:**
   - Відкрийте Telegram бота
   - Натисніть "🔒 Заблокувати"
   - Комп'ютер має заблокуватися через кілька секунд

2. **Тест розблокування:**
   - Відкрийте Telegram бота
   - Натисніть "🔓 Розблокувати"
   - Комп'ютер має розблокуватися

3. **Тест розкладу:**
   - Відкрийте Telegram бота
   - Натисніть "📅 Розклад"
   - Виберіть день тижня
   - Увімкніть розклад та встановіть час

## Крок 5: Налаштування розкладу

### 5.1 Через Telegram бота

1. Відкрийте бота
2. Натисніть "📅 Розклад"
3. Виберіть день тижня (Пн-Нд)
4. Налаштуйте:
   - **Увімкнути/Вимкнути** розклад
   - **Час початку** (наприклад, 22:00)
   - **Час кінця** (наприклад, 07:00)

### 5.2 Приклад налаштування

**Вихідні дні (Пт-Нд):**
- Початок: 22:00
- Кінець: 07:00
- Увімкнено: Так

**Будні дні (Пн-Чт):**
- Початок: 22:00
- Кінець: 07:00
- Увімкнено: Ні (або інший час)

## Крок 6: Встановлення ліміту часу

1. Відкрийте Telegram бота
2. Натисніть "📊 Статус"
3. Виберіть потрібний ліміт:
   - 15 хв
   - 30 хв
   - 60 хв
   - 2 год
   - Без ліміту

Ліміт почне відлік від моменту встановлення.

## Крок 7: Автозапуск (опціонально)

### 7.1 Створення ярлика

1. Створіть ярлик для `main.py`
2. Перемістіть ярлик в автозавантаження:
   - Натисніть `Win + R`
   - Введіть `shell:startup`
   - Перемістіть ярлик в цю папку

### 7.2 Запуск з правами адміністратора

Для повної функціональності (блокування вводу) потрібні права адміністратора:

1. Клацніть правою кнопкою на ярлик
2. Виберіть "Властивості"
3. Вкладка "Сумісність"
4. Встановіть "Запускати цю програму від імені адміністратора"

## Поширені сценарії використання

### Сценарій 1: Обмеження часу роботи

**Завдання:** Дозволити дитині працювати на комп'ютері тільки 1 годину на день.

**Рішення:**
1. Відкрийте Telegram бота
2. Натисніть "📊 Статус"
3. Виберіть "60 хв"
4. Після закінчення часу комп'ютер заблокується

### Сценарій 2: Час сну

**Завдання:** Заблокувати комп'ютер з 22:00 до 07:00 щодня.

**Рішення:**
1. Відкрийте Telegram бота
2. Натисніть "📅 Розклад"
3. Для кожного дня тижня:
   - Увімкніть розклад
   - Встановіть початок: 22:00
   - Встановіть кінець: 07:00

### Сценарій 3: Миттєве блокування

**Завдання:** Заблокувати комп'ютер зараз.

**Рішення:**
1. Відкрийте Telegram бота
2. Натисніть "🔒 Заблокувати"
3. Комп'ютер заблокується через кілька секунд

### Сценарій 4: Розблокування

**Завдання:** Розблокувати комп'ютер.

**Рішення:**
1. Відкрийте Telegram бота
2. Натисніть "🔓 Розблокувати"
3. Комп'ютер розблокується
