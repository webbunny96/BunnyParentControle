# Індекс документації

Повний список документації для системи батьківського контролю.

## Основна документація

### [README.md](../README.md)
Головна документація проекту з описом системи, можливостей, встановлення та використання.

**Зміст:**
- Опис системи
- Основні можливості
- Архітектура
- Встановлення
- Налаштування
- Використання
- Структура проекту
- Розробка

## Детальна документація

### [QUICKSTART.md](QUICKSTART.md)
Швидкий старт для нових користувачів.

**Зміст:**
- Покрокова інструкція встановлення
- Створення Telegram бота
- Перший запуск
- Налаштування розкладу
- Поширені сценарії використання

**Для кого:** Новачки, які хочуть швидко запустити систему

### [API.md](API.md)
Детальна документація API всіх модулів системи.

**Зміст:**
- Конфігурація
- Core API (config, monitor, scheduler)
- Bot API (handlers, keyboards)
- GUI API (tray_app, settings_window, blocking_window)
- Utils API (logger, qr_generator, telegram_api, env_manager)

**Для кого:** Розробники, які хочуть розширити функціональність

### [ARCHITECTURE.md](ARCHITECTURE.md)
Детальний опис архітектури системи.

**Зміст:**
- Загальна архітектура
- Компоненти системи
- Потоки даних
- Взаємодія компонентів
- Архітектурні рішення
- Масштабованість
- Безпека

**Для кого:** Розробники, які хочуть зрозуміти як працює система

### [TROUBLESHOOTING.md](TROUBLESHOOTING.md)
Посібник з усунення проблем.

**Зміст:**
- Проблеми з встановленням
- Проблеми з Telegram ботом
- Проблеми з GUI
- Проблеми з блокуванням
- Проблеми з конфігурацією
- Інші проблеми

**Для кого:** Користувачі та розробники, які стикнулися з проблемами

## Оновлення документації

Документація оновлюється при:
- Додаванні нових функцій
- Зміні API
- Виявленні нових проблем
- Зміні архітектури
